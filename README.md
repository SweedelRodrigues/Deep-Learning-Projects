# Deep Learning Projects

A collection of Deep Learning projects focused on neural networks, image classification, and image data processing using TensorFlow/Keras. This repository demonstrates practical implementations of core Deep Learning concepts through hands-on projects and model development.

---

## Projects Included

### Breast Cancer Classification using Neural Networks
- Binary classification model for detecting malignant and benign tumors
- Data preprocessing, feature scaling, and model evaluation

### Dog vs Cat Classification using Neural Networks
- Image classification model for distinguishing dogs and cats
- Image preprocessing and deep learning-based prediction

### MNIST Digit Classification
- Handwritten digit recognition using the MNIST dataset
- Multiclass classification using neural networks

### Processing Image Data
- Basic image preprocessing and transformation techniques
- Understanding image representation in numerical form

## Installation

Clone the repository:

```bash
git clone https://github.com/SweedelRodrigues/Deep-Learning-Projects.git
```

Navigate to the project directory:

```bash
cd Deep-Learning-Projects
```

Install dependencies:

```bash
pip install tensorflow numpy pandas matplotlib jupyter
```

Run Jupyter Notebook:

```bash
jupyter notebook
```
